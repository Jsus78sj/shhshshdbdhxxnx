# مصمم البلاطات المصمتة — BS 8110 Solid Slab Designer (v1.0.0)

تطبيق أندرويد متكامل مبني بـ **Flutter** يعمل بالكامل دون إنترنت (**Offline-First**) لتصميم البلاطات الخرسانية المصمتة وفق **الكود البريطاني BS 8110-1** وطريقة الشرح الجامعية المعتمدة.

---

## المميزات الرئيسية (الإصدار النهائي 1.0.0)
1. **وضعا إدخال مرنان:**
   - **تصميم بلاطة واحدة + جيرانها:** رسم تفاعلي لحواف البلاطة الأربع مع فتح حقول البلاطات المجاورة والكوابيل تلقائياً للموازنة السريعة.
   - **محرر المخطط الشبكي الكامل (`Full Floor Grid Editor`):** بناء شبكة المحاور الأفقية والرأسية كاملة، تعيين البلاطات العادية والمهبطة (`Dropped Solid Slab`) وبيت الدرج والكوابيل، مع **حاسبة الرقم السحري (`S_No. = 9 − |d₁ − d₂|`)** و**جدول تسليح السقف كاملاً** وحفظ المشاريع محلياً عبر `Hive`.
2. **وضعا حساب هندسي مع مقارنة فورية:**
   - **وضع شرح المحاضرة والاختبارات:** موازنة العزوم ($M_{UB}, k$)، صيغة عدد الأسياخ (`No Ø`)، وفحص الهطول وفق الشرح الجامعي ($B.R = 26$).
   - **وضع الكود البريطاني الصارم (`BS 8110`):** تطبيق حرفي لـ `Table 3.9` مع اكتشاف فشل الهطول واقتراح السماكة الآمنة أو حديد الضغط من `Table 3.11` وتحديث الوزن الذاتي تلقائياً.
3. **رسومات هندسية تفاعلية (`CustomPainter`):**
   - مخطط السقف الكامل بالتكبير والتحريك، مخطط عزوم الانحناء (قبل الموازنة / بعد الموازنة / مقارنة)، مسقط التسليح الأفقي مع أزرار عزل الطبقات، والقطاعين العرضيين **Section X–X** و **Section Y–Y**.
4. **كتيّب الكود البريطاني المدمج (`Offline Code Browser`):**
   - جميع الجداول والأقسام الـ **18** (`Table 1` إلى `Table 3.25` + ملحق الأعمدة) مع بحث فوري وتظليل متقاطع للصف والعمود وحاسبة تناسب خطي مدمجة.
5. **تصدير تقارير PDF باللغة العربية (`RTL`) دون إنترنت:**
   - خطوط عربية وهندسية مدمجة محلياً (`NotoSansArabic` + `DejaVuSans`) لتوليد تقارير A4 شاملة للخطوات والجداول والرسم المتجهي.
6. **جاهزية الإنتاج (`Phase 7 — QA & Release`):**
   - أيقونة تطبيق مخصصة بدقة عالية وشاشة بداية (`assets/branding/`)، إعدادات أندرويد نظيفة بدون صلاحية إنترنت، سكربتات بناء آلية لـ Windows و Linux/macOS، وحزمة اختبارات شاملة (`unit` + `golden` + `widget` + `responsive QA`).

## التشغيل السريع وبناء ملف الـ APK
لبناء ملف الـ **APK** الإنتاجي المقسّم مباشرة، راجع ملف `RELEASE_GUIDE.md` أو نفّذ:

- **Windows (PowerShell):**
  ```powershell
  powershell -ExecutionPolicy Bypass -File scripts/build_release_apk.ps1
  ```
- **Linux / macOS:**
  ```bash
  chmod +x scripts/build_release_apk.sh
  ./scripts/build_release_apk.sh
  ```


## تحميل التطبيق (APK)
من صفحة **Releases** في المستودع (عامة لأي زائر): نزّل `app-arm64-v8a-release.apk` من «أحدث نسخة».
